## 函数的前推和拉回

前推（Pushforward）和拉回（Pullback）是函数复合的两个方向

- 前推：后复合（post-composition），将用于前推的函数作用在另一个函数的输出端
- 拉回：前复合（pre-composition），将用于拉回的函数作用在另一个函数的输入端

对于函数

$$
f:A\to B
$$

其诱导的前推为

$$
f^*(-)=f\circ -
$$

前推改变原函数的输出类型

$$
f^*:\operatorname{Hom}(X,A)\to\operatorname{Hom}(X,B)
$$

其诱导的拉回为

$$
f^*(-)=-\circ f
$$

拉回改变原函数的输入类型

$$
f^*:\operatorname{Hom}(B,Y)\to\operatorname{Hom}(A,Y)
$$

这里使用 TypeScript 实现对函数的前推和拉回

```ts
type Fn<A, B> = (a: A) => B;

// 前推：后复合
function pushforward<A, B>(f: Fn<A, B>) {
  return <X>(g: Fn<X, A>): Fn<X, B> =>
    x => f(g(x));
}

// 拉回：前复合
function pullback<A, B>(f: Fn<A, B>) {
  return <Y>(g: Fn<B, Y>): Fn<A, Y> =>
    a => g(f(a));
}
```

示例为

```ts
const f = (x: number) => x > 2;
// number => boolean

// 前推：改变输出类型
const pushed = pushforward(f)(
  (s: string) => s.length
);
// (string => number) -> (string => boolean)

console.log(pushed("hello")); // true

// 拉回：改变输入类型
const pulled = pullback(f)(
  (x: boolean) => `value=${x}`
);
// (boolean => string) -> (number => string)

console.log(pulled(5)); // "value=true"
```

### 函数前推和函数拉回的结合律

复合映射也可以诱导出前推和拉回。

设两个函数为

$$
f: B \to C
\qquad
g: A \to B
$$

二者的复合为

$$
f\circ g: A \to C
$$

复合映射诱导的前推为

$$
\begin{align*}
  (f\circ g)_*(-)
  &= (f \circ g) \circ - \\
  &= f \circ (g\circ -) \\
  &= f_*(g_*(-))
\end{align*}
$$

复合映射诱导的拉回为

$$
\begin{align*}
  (f\circ g)^*(-)
  &= - \circ (f \circ g) \\
  &= (- \circ f) \circ g \\
  &= g^*(f^*(-))
\end{align*}
$$

把左侧的复合也写为前推和拉回，得到

$$
(f_* g)_*(-) = f_*(g_*(-))
$$

$$
(g^* f)^*(-) = g^*(f^*(-))
$$

因此，复合本身的结合律给出了前推和拉回的结合律

$$
(f_*g)_*h
=f_*(g_*h)
$$

$$
(f^*g)^*h
=f^*(g^*h)
$$

我们用 TypeScript 实现一个二元运算表示函数的复合

```ts
// 函数复合
function compose<A, B, C>(
  f: Fn<B, C>,
  g: Fn<A, B>
): Fn<A, C> {
  return a => f(g(a));
}
```

前推示例为

```ts
const h = (x: number) => x + 1;
const g = (x: number) => x * 2;
const f = (x: number) => `Result: ${x}`;

// 复合映射诱导的前推
const comp = pushforward(
  compose(f, g)
)(h)
// 前推左结合
const lhs = pushforward(
  pushforward(f)(g)
)(h);
// 前推右结合
const rhs = pushforward(f)(
  pushforward(g)(h)
);

for (const x of [0, 1, 2, 3]) {
  console.assert(lhs(x) === rhs(x));
  console.assert(lhs(x) === comp(x));
}
```

拉回示例为

```ts
const f = (x: number) => x + 1;
const g = (x: number) => x * 2;
const h = (x: number) => `Result: ${x}`;

// 复合映射诱导的拉回
const comp = pullback(
  compose(g, f)
)(h)
// 拉回左结合
const lhs = pullback(
  pullback(f)(g)
)(h);
// 拉回右结合
const rhs = pullback(f)(
  pullback(g)(h)
);

for (const x of [0, 1, 2, 3]) {
  console.assert(lhs(x) === rhs(x));
  console.assert(lhs(x) === comp(x));
}
```

### 作为二元运算的前推和拉回

如果进一步把前推和拉回本身当作二元运算

$$
f*g:=f_*(g)
\qquad
f\star g:=f^*(g)
$$

那么拉回和前推的结合律可以写为

$$
(f*g)*h
=f*(g*h)
$$

$$
(f\star g)\star h=f\star(g\star h)
$$

并且有

$$
g*f=f\star g
$$

即

$$
f_*(g^*(h))=g^*(f_*(h))
$$

用 TypeScript 实现两个二元运算分别表示前推和拉回

```ts
// 前推二元运算
function mul<A, B, C>(
  f: Fn<B, C>,
  g: Fn<A, B>
): Fn<A, C> {
  return pushforward(f)(g);
}

// 拉回二元运算
function star<A, B, C>(
  f: Fn<A, B>,
  g: Fn<B, C>
): Fn<A, C> {
  return pullback(f)(g);
}
```

示例为

```ts
const f = (x: number) => x + 1;
const g = (x: number) => x * 2;
const h = (x: number) => `Result: ${x}`;

// 前推左结合
const mulLeft = mul(mul(h, g), f);
//前推右结合
const mulRight = mul(h, mul(g, f));

// 拉回左结合
const starLeft = star(star(f, g), h);
// 拉回右结合
const starRight = star(f, star(g, h));

for (const x of [0, 1, 2, 3]) {
  console.assert(mulLeft(x) === mulRight(x));
  console.assert(starLeft(x) === starRight(x));
  console.assert(mulLeft(x) === starLeft(x));
}
```

## 张量的前推和拉回

张量是线性代数里的术语，这里我们将其抽象为输入类型相同的多参数函数

$$
T(x_1, x_2, \cdots, x_n): X \times X \times \cdots \times X \to Y
$$

函数 $f:Y \to A$ 诱导出一个对张量的前推

$$
f_*T(x_1, x_2, \cdots, x_n) = f(T(x_1, x_2, \cdots, x_n))
$$

即把用于前推的函数作用在张量的输出上。前推后张量的类型变为

$$
f_*T: X \times X \times \cdots \times X \to A
$$

函数 $g: B \to X$ 诱导出一个对张量的拉回

$$
g^*T(b_1, b_2, \cdots, b_n) = T(g(b_1), g(b_2), \cdots, g(b_n))
$$

即把用于拉回的函数作用在张量的每个输入上。拉回后张量的类型变为

$$
g^*T: B \times B \times \cdots \times B \to Y
$$

使用 TypeScript 实现一个张量

```ts
// 张量：X^n -> Y
type Tensor<X, Y, Args extends X[]> =
  (...args: Args) => Y;

// 张量前推：作用于输出
function tensorPushforward<A, B>(f: Fn<A, B>) {
  return <X, Args extends X[]>(
    tensor: Tensor<X, A, Args>
  ): Tensor<X, B, Args> =>
    (...xs) => f(tensor(...xs));
}

// 张量拉回：作用于每个输入
function tensorPullback<A, B>(g: Fn<A, B>) {
  return <Y, Args extends B[]>(
    tensor: Tensor<B, Y, Args>
  ): Tensor<A, Y, { [K in keyof Args]: A }> =>
    (...xs) => tensor(...xs.map(g) as Args);
}
```

示例为

```ts
const T = (x: number, y: number) => x*x + y*y;
// number^2 => number

// 张量前推
const pushed = tensorPushforward(
  (x: number) => `value=${x}`
)(T);
// number^2 => string

console.log(pushed(3, 4)) // "value=25"

// 张量拉回
const pulled = tensorPullback(
  (x: boolean) => x ? 2 : 3
)(T);
// boolean^2 => number

console.log(pulled(false, true)) // 13
```

### 张量前推的结合律

设张量为

$$
T:X^n\to Y
$$

以及两个函数

$$
f:Y\to A
\qquad
g:A\to B
$$

复合函数 $g\circ f:Y\to B$ 诱导的前推为

$$
\begin{align*}
  (g\circ f)_*T(x_1,\cdots,x_n)
  &= (g\circ f)(T(x_1,\cdots,x_n)) \\
  &= g(f(T(x_1,\cdots,x_n))) \\
  &= g_*(f_*T)(x_1,\cdots,x_n)
\end{align*}
$$

因此

$$
(g\circ f)_*T=g_*(f_*T)
$$

将左侧的函数复合写为前推，得到张量前推的结合律

$$
(g_*f)_*T=g_*(f_*T)
$$

代码示例为

```ts
const T = (x: number, y: number) => x*x + y*y;
const f = (x: number) => x + 1;
const g = (x: number) => `value=${x}`;

// 张量前推左结合
const pushLeft = tensorPushforward(
  pushforward(g)(f)
)(T);
// 张量前推右结合
const pushRight = tensorPushforward(g)(
  tensorPushforward(f)(T)
);

console.log(pushLeft(2, 3)); // value=14
console.log(pushRight(2, 3)); // value=14
```

### 张量拉回的结合律

设张量为

$$
T:X^n\to Y
$$

以及两个函数

$$
h:D\to X
\qquad
k:C\to D
$$

复合函数 $h\circ k:D\to X$ 诱导的拉回为

$$
\begin{align*}
  (h\circ k)^*T(c_1,\cdots,c_n)
  &=T((h\circ k)(c_1),\cdots,(h\circ k)(c_n)) \\
  &=T(h(k(c_1)),\cdots,h(k(c_n))) \\
  &=h^*T(k(c_1),\cdots,k(c_n)) \\
  &=k^*(h^*T)(c_1,\cdots,c_n)
\end{align*}
$$

因此

$$
(h\circ k)^*T=k^*(h^*T)
$$

将左侧的函数复合写为拉回，得到张量拉回的结合律

$$
(k^*h)^*T=k^*(h^*T)
$$

代码示例为

```ts
const T = (x: number, y: number) => x*x + y*y;
const h = (x: string) => Number(x);
const k = (x: boolean) => x ? "2" : "3";

// 张量拉回左结合
const pullLeft = tensorPullback(
  (x: boolean) => h(k(x))
)(T);
// 张量拉回右结合
const pullRight = tensorPullback(k)(
  tensorPullback(h)(T)
);

console.log(pullLeft(true, false)); // 13
console.log(pullRight(true, false)); // 13
```

### 张量前推和张量前推的交换律

设

$$
f:Y\to A
\qquad g:B\to X
$$

那么有

$$
\begin{align*}
  f_*(g^*T)(b_1,\cdots,b_n)
  &=f(T(g(b_1),\cdots,g(b_n))) \\
  &=g^*(f_*T)(b_1,\cdots,b_n)
\end{align*}
$$

得到张量前推和张量拉回的交换律

$$
f_*(g^*T)=g^*(f_*T)
$$

即对张量先前推再拉回等于先拉回再前推。

代码示例为

```ts
const T = (x: number, y: number) => x*x + y*y;
const f = (x: number) => x + 1;
const g = (x: string) => Number(x);

// 先拉回再前推
const left = tensorPushforward(f)(
  tensorPullback(g)(T)
);
// 先前推再拉回
const right = tensorPullback(g)(
  tensorPushforward(f)(T)
);

console.log(left("he", "llo")); // 14
console.log(right("he", "llo")); // 14
```
